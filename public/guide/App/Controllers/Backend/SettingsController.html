SettingsController

class SettingsController extends BackendController

Controller per la configurazione globale delle variabili e dei parametri del sistema.

Gestisce l'interfaccia preposta all'impostazione di parametri applicativi (generali, autenticazione, upload, email), applicando un pattern in cui i dati persistenti a livello di DB sovrascrivono i default cablati nei file di configurazione.
