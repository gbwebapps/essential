EmailService

class EmailService

Servizio centralizzato per la gestione e l'invio di comunicazioni e-mail transazionali dal backend.

Astrae l'interazione con il servizio e-mail nativo del framework, standardizzando il rendering dei template HTML, la localizzazione dinamica dell'oggetto e la registrazione avanzata nei log in caso di fallimenti del protocollo SMTP.

bool sendActivationEmail(object $row, string $rawToken, string $module, string $template, string $subjectLangKey)

Compila e trasmette un'e-mail contenente un token operativo (es. attivazione account o reset password).

Il metodo elabora dinamicamente il template HTML in base al modulo chiamante, applicando l'escaping preventivo sui dati anagrafici dell'utente per ragioni di sicurezza. Formatta l'oggetto localizzato iniettando nome e cognome e affida il payload al servizio di spedizione, intercettando eventuali anomalie per facilitare il debugging.

Parameters

object $row

Oggetto contenente i dati anagrafici dell'utente destinatario (richiede firstname, lastname, email)
string $rawToken

Il token crittografico temporaneo in formato in chiaro da iniettare nel corpo del messaggio
string $module

Il namespace del modulo operativo (es. 'admins', 'auth') per risolvere il percorso fisico della vista
string $template

Il nome del file (senza estensione) contenente il layout HTML parziale dell'e-mail
string $subjectLangKey

La chiave di localizzazione per estrarre l'oggetto del messaggio (compatibile con sprintf)

Return Value

bool

Esito della spedizione: true se il server SMTP ha accettato il messaggio, false in caso di errore
