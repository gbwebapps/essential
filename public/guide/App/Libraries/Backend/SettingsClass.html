SettingsClass

class SettingsClass

Classe di supporto (utility/presentazione) dedicata alla gestione dell'interfaccia delle Impostazioni (Settings).

Centralizza la logica di configurazione visiva, predisponendo l'iniezione dinamica di librerie esterne (es. Tom Select) e fornendo dizionari di dati strutturati (fusi orari, formati data, lingue supportate) indispensabili per popolare correttamente i selettori (dropdown) del pannello di controllo.

array getDateFormats()
